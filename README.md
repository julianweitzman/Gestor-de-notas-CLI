# Gestor de notas

Proyecto en migración de Python a C#.

La implementación anterior está archivada en [`legacy/python/`](legacy/python/), separada del código de la nueva aplicación. Incluye la CLI, la API, la persistencia SQLite, las pruebas y la configuración de dependencias. En esta rama todavía no hay una implementación en C#.

La [documentación de Python](legacy/python/README.md) y la [guía de uso anterior](legacy/python/Documentacion.md) se conservan como referencia para la migración. Para ejecutar sus comandos de instalación o pruebas, primero cambiá al directorio del archivo:

```powershell
cd legacy/python
```

Mover estos archivos no modifica las notas guardadas en el directorio de datos del usuario.
